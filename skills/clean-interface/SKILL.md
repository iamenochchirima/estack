# Clean interface

Make the product clear, polished and easy to use. Follow the user's references and approved direction. Clean does not mean empty or generic.

## Design

- Identify the main task and primary action before choosing a layout.
- Reuse established fonts, colours and components. Keep typography, spacing and alignment consistent.
- Give each element a reason to exist. Remove repeated headings, redundant labels and decorative badges.
- Use compact tables, lists and grouped sections when appropriate. Avoid a card around every item or an oversized tile for every metric.
- Keep colours, borders and shadows restrained. Avoid decorative gradients, glow and dashboard filler unless requested.
- Keep common actions visible. Hide secondary detail behind a disclosure, while keeping essential information accessible.
- Use real brand assets. Graphics and demos should explain the product. Animate meaningful movement or state changes.

## Copy

- Use short, plain labels and sentence case.
- Name actions precisely: "Save changes", "Connect your agent", "Delete account".
- Cut slogans, repeated explanations and technical detail that does not help the user act.
- Make empty, loading, success and error states useful. Give a next action when needed.
- Preserve necessary context, accessibility labels and destructive-action warnings.

## Finish

- Inspect the rendered screen on desktop and mobile. Fix overflow, awkward wrapping and cramped controls.
- Check the main action, keyboard focus, contrast and reduced motion.
- Review screenshots. Remove or simplify anything competing with the main task.
- Preserve working behaviour and stay within the requested scope.
